Instrumentation

Three lines in. Tracing on.

No agents to babysit, no endpoint YAML to memorize. The SDK auto-discovers your framework and starts exporting on first request.

Auto-instrumented by defaultHTTP servers, DB drivers, message queues, and fetch — instrumented the moment they're imported.
Local sampling, tail-based globallyHead-sample cheaply on the host. The collector makes the final keep/drop call with full trace context.
Exports metrics tooThe RED metrics your dashboards expect are generated from the same spans. One source of truth.
main.go Go 
// main.go — the entire integration
package main

import (
	"net/http"
	_ "fluxtrace.dev/otel"  // auto-instrumentation
)

func main() {
	mux := http.NewServeMux()

	mux.Handle("/v2/checkout", checkoutHandler{})

	// tail sampling policy, evaluated by the collector
	flux.KeepIf(flux.Any(
		flux.Error(),
		flux.Latency("p95"),
		flux.Attribute("checkout.tier", "enterprise"),
	))

	http.ListenAndServe(":8080", mux) // tracing on ✓
}
